Equal sampling variances

When all sampling variances are equal and \(\tau^2 = 0\), the meta-analytic weight matrix is proportional to the identity matrix. In this case, flipscores provides a useful benchmark for the implementation in flipmeta.

fit_glm <- glm(

fit_fs <- flipscores(

Heterogeneous sampling variances

With heterogeneous sampling variances, the meta-analytic model directly assumes

\[ \operatorname{Var}(y_i) = v_i \]

and therefore

\[ W = \operatorname{diag}(1/v_i). \]

A weighted Gaussian GLM does not provide the same direct benchmark for the sign-flipping standardization. We therefore compare flipmeta directly with the analytical expressions obtained by specializing the score sign-flipping test to the meta-regression model.

We consider ablat as the focal moderator and year as a nuisance moderator.

fit_rma <- rma(
    yi,
    vi,
    mods = ~ ablat + year,
    data = dat,
    method = "EE"
)

fit_fm <- flipmeta(
    fit_rma,
    flips = flips
)

Score contributions

Let \(x\) denote the focal moderator and \(Z\) the nuisance design matrix. Under \(H_0:\beta_x=0\),

\[ \hat\gamma_0 = (Z^\top WZ)^{-1} Z^\top Wy \]

and

\[ r_0 = y-Z\hat\gamma_0. \]

The focal predictor is residualized with respect to the nuisance covariates as

\[ \tilde{x} = x-Z(Z^\top WZ)^{-1}Z^\top Wx. \]

The individual score contributions are then

\[ \nu_i = \tilde{x}_i w_i r_{0i}. \]

y <- dat$yi
x <- dat$ablat
Z <- model.matrix(~ year, data = dat)

k <- length(y)

w <- 1 / dat$vi
W <- diag(w)

gamma0 <- solve(
    crossprod(Z, W %*% Z),
    crossprod(Z, W %*% y)
)

r0 <- drop(
    y - Z %*% gamma0
)

gamma_x <- solve(
    crossprod(Z, W %*% Z),
    crossprod(Z, W %*% x)
)

x_tilde <- drop(
    x - Z %*% gamma_x
)

score_contributions <- x_tilde * w * r0

score_oracle <- sum(score_contributions)

score_flipmeta <- fit_fm$summary_table$score[
    fit_fm$summary_table$coefficient == "ablat"
]

c(
    oracle = score_oracle,
    flipmeta = score_flipmeta,
    ratio = score_flipmeta / score_oracle
)
   oracle  flipmeta     ratio 
-2121.097 -2121.097     1.000

Standardized flipped statistics

Define

\[ H = W^{1/2}Z (Z^\top WZ)^{-1} Z^\top W^{1/2} \]

and

\[ P=I-H. \]

For flip \(b\), the flipped score is

\[ S_b = \sum_i f_{bi}\nu_i, \]

and the flip-specific variance term is

\[ C_b = x^\top W^{1/2} P F_b P F_b P W^{1/2}x. \]

The standardized statistic is

\[ T_b = \frac{S_b}{\sqrt{C_b}}. \]

sqrtW <- diag(sqrt(w))

H <- sqrtW %*%
    Z %*%
    solve(crossprod(Z, W %*% Z)) %*%
    t(Z) %*%
    sqrtW

P <- diag(k) - H

score_flipped <- drop(
    flips %*% score_contributions
)

variance_flipped <- numeric(nrow(flips))

for (b in seq_len(nrow(flips))) {

    F <- diag(flips[b, ])

    variance_flipped[b] <- drop(
        t(x) %*%
            sqrtW %*%
            P %*%
            F %*%
            P %*%
            F %*%
            P %*%
            sqrtW %*%
            x
    )
}

T_oracle <- score_flipped / sqrt(variance_flipped)
T_flipmeta <- fit_fm$Tspace[, "ablat"]

The two permutation spaces should now coincide directly.

ratio <- T_flipmeta / T_oracle

Fixed heterogeneity

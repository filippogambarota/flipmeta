# Summarize a flipmeta model

Prints a summary of a fitted `flipmeta` object.

## Usage

``` r
# S3 method for class 'fm'
summary(object, digits = 4, width = 58, ...)
```

## Arguments

- object:

  An object of class `"fm"`.

- digits:

  Number of digits used to format numeric values.

- width:

  Width of the label column used for aligned output.

- ...:

  Reserved for compatibility with the
  [`summary()`](https://rdrr.io/r/base/summary.html) generic.

## Value

Invisibly returns `object`.

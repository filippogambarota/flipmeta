# Print an aligned label-value line

Prints a label and a value using a fixed-width label column.

## Usage

``` r
.print_line(label, value, width = 58)
```

## Arguments

- label:

  A character string used as the left-hand label.

- value:

  A character string used as the right-hand value.

- width:

  Width of the label column.

## Value

Invisibly returns `NULL`.

# Print a joined flipmeta model list

Prints a compact summary of a joined `flipmeta` object produced from a
list of models.

## Usage

``` r
# S3 method for class 'fml'
print(x, digits = 4, max_rows = 20, ...)
```

## Arguments

- x:

  An object of class `"fml"`.

- digits:

  Number of digits used to format numeric values.

- max_rows:

  Maximum number of rows printed from the joined summary table.

- ...:

  Reserved for compatibility with the
  [`print()`](https://rdrr.io/r/base/print.html) generic.

## Value

Invisibly returns `x`.

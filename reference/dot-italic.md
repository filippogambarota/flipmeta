# Italicize console text using ANSI escape codes

Adds ANSI escape codes for italic text. If `ansi = FALSE`, the input is
returned unchanged.

## Usage

``` r
.italic(x, ansi = interactive())
```

## Arguments

- x:

  A character vector.

- ansi:

  Logical. If `TRUE`, ANSI escape codes are added.

## Value

A character vector.
